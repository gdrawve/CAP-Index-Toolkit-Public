# CAP Index Toolkit 1.0.0

Release date: October 14, 2026.

Version 1.0.0 establishes the current toolkit as the first release baseline. Prior 0.x packages are testing and exploration builds and remain part of development history. This version changes version metadata and release wording, not analytical calculations or outputs. Ribbon callbacks use a v1-specific namespace.

The release includes data preparation and coverage review, time fields, hundred blocks and synthetic block addresses, Census geocoding, reviewed NIBRS crosswalks, analysis scope, concentration, temporal heat maps, repeat locations, hot streets, Single Site, trends, period comparisons, seasonality, reporting/export, Excel Essentials and the CAP tool guide/About window.

Disable older CAP Index add-ins before enabling CAP-Index-Toolkit-1.0.0.xlam. Do not load multiple toolkit versions together. Existing data workbooks are retained; rebuild analyses to incorporate changed source data.

CAP Index ownership notices remain in effect. The package is unsigned. Changing its version does not constitute digital signing or independent approval for company deployment. Existing data accuracy, coverage, incident/offense-count and synthetic-location limitations continue to apply. Automated mapping remains deferred.

The build's validation.txt and SHA256.txt accompany the add-in. Real incident datasets and generated build packages are excluded from the source repository.
